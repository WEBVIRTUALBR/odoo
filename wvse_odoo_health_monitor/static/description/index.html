Description

wvse_odoo_health_monitor is a modern monitoring experience for Odoo 15.0 focused on health visibility, operational status, alerts, locale readiness, dependency awareness, and customer-facing service transparency. The layout was rebuilt with Bootstrap-driven structure for stronger compatibility in Odoo module descriptions while preserving a modern Webvirtual visual identity.
