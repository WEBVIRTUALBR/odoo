Overview
Description

wvse_odoo_health_monitor is a next-generation monitoring module prepared for Odoo 15.0. It extends the standard environment with health checks, visibility panels, alert-oriented resources, and a clean presentation focused on compatibility testing inside Odoo module descriptions.

Core Functionalities
⚡Real-Time SyncBidirectional sync with sub-second latency via WebSockets.
🎨Custom BrandingWhite-label the interface with your company colors and logo.
🔍Advanced SearchFull-text search with saved views and faceted navigation.
📱Mobile FirstResponsive design optimized for touch and mobile devices.
🔒Role-Based AccessFine-grained permissions at field, view, and record level.
🌐Multi-LanguageShipped with 27 locales, auto-detected from browser.
