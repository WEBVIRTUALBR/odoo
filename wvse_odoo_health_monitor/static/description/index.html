Description

Webvirtual Health Monitor is a modern monitoring experience for Odoo 15.0 focused on health visibility, operational status, alerts, locale readiness, dependency awareness, and customer-facing service transparency. The layout was rebuilt with Odoo-store-safe structure while preserving the modern Webvirtual visual identity.
