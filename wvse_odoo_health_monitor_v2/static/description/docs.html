Neon Logic CRM Pro

Welcome to the official documentation for Neon Logic CRM Pro, a next-generation customer relationship management module built natively for Odoo 17. This guide covers installation, configuration, API usage, and advanced extension patterns.

Installation

Follow these steps to install Neon Logic CRM Pro on your Odoo instance.

1. Download the Module

Purchase and download the module from the Odoo App Store. Extract the archive — it contains a single folder named neon_logic_crm.

2. Add to Addons Path

Copy the module folder to your Odoo addons directory:

# Copy module to addons path
cp -r neon_logic_crm /opt/odoo/custom-addons/

# Verify folder structure
ls /opt/odoo/custom-addons/neon_logic_crm/
# Expected: __manifest__.py  __init__.py  models/  views/  static/

3. Update Addons List

Restart Odoo and update the module list:

# Restart Odoo service
sudo systemctl restart odoo

# Or update via CLI
./odoo-bin -d your_database -u neon_logic_crm --stop-after-init

4. Install via UI

Navigate to Settings → Apps, search for Neon Logic CRM Pro, and click Install.

⚠️ Dependency Order

Ensure crm and mail base modules are installed before activating this module. The installer will handle this automatically.

Configuration

General Settings

After installation, navigate to CRM → Configuration → Neon Logic Settings to configure the module.

Pipeline Settings

SettingDefaultDescription
pipeline_auto_assignTrueAuto-assign leads to available salesperson based on workload
lead_scoring_enabledFalseEnable AI-powered lead scoring (requires API key)
sla_trackingTrueTrack SLA compliance across pipeline stages
realtime_dashboardTrueEnable WebSocket live updates on dashboards

Access Rights

The module ships with three predefined roles:

  • CRM User — Can view and edit own leads. No configuration access.
  • CRM Manager — Full pipeline access across all salespersons. Configuration read-only.
  • CRM Administrator — Full access including settings, automations, and API keys.

Email Integration

Configure your outgoing mail server under Settings → Technical → Outgoing Mail. The CRM module uses the alias system to automatically convert incoming emails to leads:

# Example: catch-all alias for lead creation
Alias: leads@yourcompany.com → CRM / New Lead
Model: crm.lead
Default values: {"type": "lead", "tag_ids": [3]}

REST API

The module exposes a versioned REST API at /api/nl/v1/. All endpoints require authentication.

Authentication

Use Bearer token authentication. Obtain a token via the standard Odoo session or generate an API key in Settings → API Keys:

curl -X POST https://your-odoo.com/api/nl/v1/auth \
  -H "Content-Type: application/json" \
  -d '{"login": "admin", "password": "your-password", "db": "your_db"}'

# Response
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "expires_in": 86400
}

Leads Endpoint

Extension Hooks

Override the scoring engine by inheriting nl.score.engine:

class MyCustomScorer(models.AbstractModel):
    _inherit = 'nl.score.engine'

    def _compute_score(self, lead):
        score = super()._compute_score(lead)
        # Add your custom scoring logic
        if lead.partner_id.country_id.code == 'PT':
            score += 10
        return score

FAQ

Does this work with Odoo Community?

Yes. All core features are compatible with Odoo 17 Community. Some features like the enterprise dashboard layout require the Enterprise edition.

Can I use this with multiple companies?

Yes. Full multi-company isolation is supported. Each company has its own pipeline stages, SLA rules, and team assignments.

How do I update to a new version?

Download the new version from the App Store, replace the module folder, and run:

./odoo-bin -d your_database -u neon_logic_crm --stop-after-init

Troubleshooting

Module not appearing in App list

Ensure the folder name matches exactly neon_logic_crm and that the addons path in odoo.conf includes the parent directory.

WebSocket dashboard not updating

Verify that your reverse proxy (nginx/apache) allows WebSocket upgrade headers. See proxy configuration guide.
